# DemoSwiftUI

☕ Coffee Shop UI App – Onboarding, Home & Detail Screens
This project showcases a beautifully designed Coffee Shop mobile app UI built using SwiftUI. It includes three main screens:

Onboarding Screen – A smooth and modern introduction to the app experience.
Home Screen – Displays a list of coffee options with appealing visuals and clean layout.
Detail Screen – Provides detailed information about a selected coffee item with an elegant interface.

Perfect for UI/UX inspiration or as a starter template for coffee-related mobile applications.
